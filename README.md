Three-Phase Fault Analysis Using Overcurrent Relay

📌 Project Overview

This project presents a three-phase power system fault analysis model developed using MATLAB/Simulink. The system is modeled to study fault conditions and demonstrate the operation of an overcurrent relay-based protection system.

The simulation analyzes the behavior of the system during faults and shows how the protection system detects excessive current and isolates the faulty section using a circuit breaker.

⚙️ Software Used

- MATLAB
- Simulink
- Simscape Electrical

🔧 Main Components

- Three-Phase Voltage Source
- Three-Phase Transmission Line
- Transformer
- Three-Phase Load
- Overcurrent Relay
- Circuit Breaker
- Fault Block
- Voltage and Current Measurement Blocks

🔬 Simulation

The Simulink model is used to analyze the system under fault conditions. When the fault causes the current to exceed the relay's preset threshold, the overcurrent relay operates and sends a trip signal to the circuit breaker, disconnecting the faulty section.

📊 Results

The simulation allows observation of:

- Three-phase voltage and current waveforms
- Increase in current during fault conditions
- Operation of the overcurrent relay
- Circuit breaker tripping
- Isolation of the faulty section
